# คู่หาร — แอปหารค่าใช้จ่ายกับแฟน (PWA)

ไฟล์ในโฟลเดอร์นี้:
- `index.html` — หน้าตาแอป
- `style.css` — ดีไซน์
- `app.js` — โค้ดที่คุยกับฐานข้อมูล + คำนวณยอดหาร
- `manifest.json`, `sw.js`, `icons/` — ทำให้ติดตั้งเป็นแอปบนมือถือได้ (PWA)

ก่อนใช้งานได้จริง ต้องทำ 2 ขั้นตอน: **(1) ตั้งค่า Firebase** ให้ข้อมูลของคุณกับแฟน sync กัน แล้ว **(2) เอาขึ้น GitHub Pages** ให้เปิดจากมือถือได้จริง

---

## ขั้นตอนที่ 1: ตั้งค่า Firebase (ทำครั้งเดียว ใช้เวลา ~10 นาที)

1. เข้า https:/ผ/console.firebase.google.com แล้ว login ด้วย Google account
2. กด **"Add project"** → ตั้งชื่อโปรเจกต์ (เช่น `kuhaan-app`) → กด Continue ไปเรื่อยๆ จนสร้างเสร็จ (ปิด Google Analytics ก็ได้ ไม่จำเป็น)
3. ในเมนูซ้าย เลือก **Build → Firestore Database** → กด **Create database**
   - เลือก location ใกล้ๆ (เช่น `asia-southeast1`)
   - เลือกโหมด **Start in test mode** (จะเปิดให้อ่าน/เขียนได้อิสระ 30 วัน — พอสำหรับใช้ส่วนตัว 2 คน แต่ **ห้ามใส่ข้อมูลอ่อนไหวจริงจัง** เพราะใครมีรหัสห้องก็เข้าดูได้ ดูหมายเหตุด้านล่าง)
4. กลับไปหน้าโปรเจกต์หลัก กดไอคอนรูปเฟือง (Project settings) → เลื่อนลงมาที่ **"Your apps"** → กดไอคอนรูป `</>` (Web app)
5. ตั้งชื่อแอปอะไรก็ได้ → กด Register app
6. หน้าจอจะโชว์โค้ดคล้ายๆ นี้:
   ```js
   const firebaseConfig = {
      apiKey: "AIzaSyAAy_EwrHSGcQGFtqaffQ3cmrbAeNc0DMw",
      authDomain: "app-hann.firebaseapp.com",
      projectId: "app-hann",
      storageBucket: "app-hann.firebasestorage.app",
      messagingSenderId: "546410969266",
      appId: "1:546410969266:web:e450067079cdbbf0a5f1ab",
      measurementId: "G-GWRLG21LKN"
   };
   ```
   **คัดลอกค่าตรงนี้ทั้งหมด**
7. เปิดไฟล์ `app.js` ในโฟลเดอร์นี้ → หาบรรทัด `const firebaseConfig = {...}` ที่อยู่บนสุด → **แทนที่ด้วยค่าที่คัดลอกมา**

> **หมายเหตุเรื่องความปลอดภัย:** โหมด "test mode" ของ Firestore จะหมดอายุใน 30 วันแล้วจะบล็อกการเข้าถึงทั้งหมด (แอปจะใช้ไม่ได้) ถ้าอยากใช้ต่อ ให้กลับไปที่ Firestore → แท็บ **Rules** แล้วตั้งกฎแบบนี้แทน (เปิดให้ใช้ได้ตลอดโดยไม่ต้อง login เพราะแอปนี้ไม่มีระบบสมาชิก):
> ```
> rules_version = '2';
> service cloud.firestore {
>   match /databases/{database}/documents {
>     match /{document=**} {
>       allow read, write: if true;
>     }
>   }
> }
> ```
> ข้อแลกเปลี่ยนคือใครก็ตามที่รู้ **ทั้ง projectId และเดารหัสห้อง** จะเข้าดู/แก้ข้อมูลได้ — สำหรับแอปหารค่าใช้จ่ายกับแฟน ความเสี่ยงนี้ถือว่ารับได้ แต่อย่าใช้วิธีนี้กับข้อมูลสำคัญอื่น

## ขั้นตอนที่ 2: เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `kuhaan-app`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลาก-วางผ่านหน้าเว็บ GitHub ก็ได้ หรือ `git push` ถ้าถนัด command line — เหมือนที่เคยทำกับโปรเจกต์แผนที่)
3. ไปที่ repo → **Settings → Pages**
4. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch** → Branch เลือก `main` และโฟลเดอร์ `/ (root)` → กด Save
5. รอ 1-2 นาที แล้วเว็บจะขึ้นที่ `https://ชื่อบัญชีคุณ.github.io/kuhaan-app/`

---

## ขั้นตอนที่ 3: เริ่มใช้งานกับแฟน

1. เปิดลิงก์ที่ได้จาก GitHub Pages บนมือถือทั้งสองคน
2. ตั้ง **รหัสห้อง** อะไรก็ได้ที่จำง่าย (เช่นชื่อเล่นคู่ + เลข) แล้วบอกแฟนให้พิมพ์รหัสเดียวกัน
3. คนแรกที่เข้าห้องจะเป็นคนตั้งชื่อทั้งสองคน (คนหลังพิมพ์ชื่อไปก็ไม่มีผล ระบบจะใช้ชื่อที่ตั้งไว้ตอนสร้างห้อง)
4. เลือกว่าตัวเองคือ "คนที่ 1" หรือ "คนที่ 2" ให้ตรงกับที่อีกฝ่ายเลือก (คนละอันกัน)
5. กด "เพิ่มลงหน้าจอหลัก" จาก browser (Safari: กดปุ่ม Share → Add to Home Screen / Chrome: เมนู ⋮ → Add to Home screen) จะได้ไอคอนแอปเหมือนแอปจริง

---

## ถ้าอยากต่อยอด

- เพิ่มหมวดหมู่รายจ่าย (อาหาร, เดินทาง, ที่พัก) แล้วกรอง/สรุปตามหมวด
- เพิ่มปุ่ม "เคลียร์ยอดแล้ว" เพื่อบันทึกว่าจ่ายคืนกันแล้ว (reset ยอดโดยไม่ลบประวัติ)
- เปลี่ยนจากหาร 50/50 คงที่ เป็นใส่สัดส่วนเองได้ (เช่น 60/40)

ถ้าอยากให้ช่วยต่อจุดไหน บอกได้เลย
